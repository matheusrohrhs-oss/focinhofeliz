# 🐾 Focinho Feliz

> Uma plataforma desenvolvida para gestão, adoção e cuidados com animais de estimação, proporcionando mais bem-estar para pets e praticidade para tutores e ONGs.

---

## 📌 Sobre o Projeto

O **Focinho Feliz** nasce com o propósito de conectar tutores, ONGs, protetores independentes e serviços para pets em um único lugar. O projeto visa facilitar a busca por adoções responsáveis, gerenciamento de saúde/cuidados do pet e integração de serviços.

---

## ✨ Funcionalidades

- [x] **Cadastro e Perfil do Pet:** Armazenamento de informações como idade, raça, histórico de vacinas e fotos.
- [x] **Módulo de Adoção:** Listagem e filtragem de animais disponíveis para adoção responsável.
- [x] **Mapeamento & Serviços:** Busca por petshops, clínicas veterinárias e protetores parceiros próximos.
- [x] **Interface Responsiva:** Design otimizado para navegação fluida em dispositivos móveis e desktop.

## 🚀 Como Executar o Projeto

### Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Git](https://git-scm.com)
- [Node.js](https://nodejs.org/) (se aplicável ao projeto)

### 📁 Passo a Passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/matheusrohrhs-oss/focinhofeliz.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd focinhofeliz
   ```

3. **Instale as dependências** *(caso utilize gerenciador de pacotes)*:
   ```bash
   npm install
   # ou
   yarn install
   ```

4. **Execute a aplicação:**
   ```bash
   npm start
   # ou abra o arquivo index.html no seu navegador
   ```
